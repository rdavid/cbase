== About

A collection of basic C functions and examples.

== Build

The project uses {url-redo}[`redo`], Daniel J. Bernstein's build system.
Sergey Matveev's {url-goredo}[`goredo`] implementation works well.

== Test

`redo test` runs the unit tests.
`redo lint` applies the following linters to the source files and commit
messages:
{url-actionlint}[`actionlint`],
{url-checkmake}[`checkmake`],
{url-conform}[`conform`],
{url-reuse}[`reuse`],
{url-typos}[`typos`],
{url-yamllint}[`yamllint`].
